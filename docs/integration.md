# 🔌 Fluxlock Integration Guide

## Overview

Fluxlock enforces time-bound identity validity.

Instead of assuming identity is always valid, Fluxlock ensures:

valid key + valid time = valid identity

---

## API Endpoint

POST /validate

---

## Request

```json
{
  "identity": "ID-1001",
  "epoch": 1
}
